# 通用格式与兼容性边界

公开申请及总表采用十个通用字段：记录编号、位置、资源标识、业务类别、IPv4地址、IPv6地址、网关、掩码、组织、联系人。规划示例采用四个字段：位置、IPv4网段、IPv6网段、用途。不复用原业务模板的完整字段组合。

| 功能 | 读取规则 | 已验证边界 |
| --- | --- | --- |
| 规划界面 | 首个工作表、首行列名，动态显示列 | 两条通用示例；工作表名称可变 |
| 申请界面 | 首个工作表、首行列名，忽略空行 | 空记录编号可显示 |
| 独立分配核心 | 通用字段，按位置和资源标识匹配 | 支持常见旧列名、空格及星号；重复映射拒绝导入 |
| 工作统计 | 普通文件名；首表前十行寻找组织、联系人 | 兼容常见旧表头及旧文件名前缀 |
| IPv6 实例 | JSON 键 area、ipv6、combo_select | ipv6 必须为合法 IPv6 |

兼容层只映射个别常见列名，例如站点、设备点位、申请单位、申请人；不包含完整客户模板。独立核心导出时恢复输入列名，并保留附加列。未知业务列仍可能敏感，只用于本机工作副本，不能因此上传。

## 数据与构建

个人前缀、文件路径和日志存入操作系统用户数据目录，可通过 `IP_SUITE_DATA_DIR` 指定。不会自动读取旧源码目录中的私有配置。源码仅保留静态字段映射、干净默认实例及图标。

日志采用受限格式，舍弃原始业务消息和堆栈。构建统一通过 `scripts/build.py` 和 `packaging/IP-Suite-Tool.spec`，不打包用户配置、日志或示例表。可以使用 `python scripts/check_public_content.py --binary <程序文件>` 检查归档。

公开示例必须保持已审核的字段、单表结构及校验值；检查拒绝文档元数据、公式、命名区域、外链和隐藏附加表。历史工具已移出源码树保存在私有归档，检查会拒绝重新引入 `legacy/`。

## 功能限制

IP 文本替换不会清除全部企业名称、人员、图片、批注、外链或隐藏对象，不能作为整份文档公开的依据。规划编辑器只导出首表数据，不保证保留公式、多表、宏或样式，请另存副本。

地址分配界面仅归档图片和申请表。独立核心仍使用静态占位地址，未实现生产地址池及冲突管理。测试成功不能替代业务验收。

## 发布边界

当前版本使用新的独立历史。不得合并原业务仓库分支、标签或旧安装包。旧业务仓库及其 Actions 已删除，同名新私有仓库从单根提交开始；旧资料仅保留于仓库之外的私有 ZIP。源码公开授权仍须确认。发布检查只能阻止本项目自动发布，无法阻止管理员手动修改可见性或上传文件。
