# 通用合成示例

三份示例从零创建，使用虚构位置、组织、联系人和资源标识，以及文档专用地址。没有复制业务工作簿的工作表、元数据、外链或隐藏对象，也不保留原业务模板的完整字段组合。

- `network_plan.xlsx`：位置、IPv4网段、IPv6网段、用途，共四列、两条规划。
- `requests.xlsx`：记录编号、位置、资源标识、业务类别、IPv4地址、IPv6地址、网关、掩码、组织、联系人，共十列、两条待处理申请，记录编号允许为空。
- `allocations.xlsx`：与申请表相同的通用十列，一条历史记录，用于验证重复资源检测。

普通文件名可以直接用于工作统计。`manifest.json` 记录经检查示例的 SHA256；修改示例内容会阻止公开内容检查。不要用业务数据替换示例或直接更新校验值绕过审查；新增示例必须重新检查其内容和工作簿内部结构。

业务工作副本请存放在源码目录之外。程序保留少量常见旧列名的导入映射，导出恢复输入列名；这不代表提供客户模板或保证兼容任意业务工作簿。

地址分配界面当前仅归档附件。独立核心仍使用占位地址，不能用于生产地址池。
